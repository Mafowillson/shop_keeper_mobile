# ShopKeeper Flutter App - Project Summary

## Overview

ShopKeeper is a production-grade Flutter mobile application for inventory and shop management, built specifically for small retail businesses in Cameroon. The app implements a complete Clean Architecture pattern with Provider state management, functional programming using fpdart, and comprehensive dependency injection via GetIt and injectable.

## Architecture Overview

### Clean Architecture Layers

**Domain Layer (Pink)**
- Pure Dart, framework-independent
- Contains business logic and entities
- Defines repository interfaces
- Implements use cases
- No external dependencies

**Data Layer (Green)**
- Implements domain repositories
- Contains models with JSON serialization
- Manages remote and local datasources
- Currently uses mock data (ready for backend integration)
- Handles data transformation (Model ↔ Entity)

**Presentation Layer (Blue)**
- Flutter widgets and screens
- Provider-based state management
- User interface and interactions
- Router configuration with go_router
- Reusable UI components

## Data Flow Example

```
User taps "Add Product" button
    ↓
ProductScreen widget
    ↓
EditProductScreen opens
    ↓
User fills form and taps "Save"
    ↓
ProductProvider.saveProduct() called
    ↓
SaveProductUseCase validates input
    ↓
IProductRepository.saveProduct() called
    ↓
ProductRepositoryImpl calls datasource
    ↓
MockProductRemoteDataSource saves data
    ↓
ProductModel converted to Product entity
    ↓
Result returned to provider
    ↓
Provider notifies listeners
    ↓
UI updates with success message
```

## Backend Integration

The app is designed for easy backend integration:

1. Replace mock datasources with real implementations
2. Implement HTTP calls to Golang backend
3. Update models to match API responses
4. No changes needed to providers, use cases, or screens

Example datasource replacement:
```dart
@LazySingleton(as: IProductRemoteDataSource)
class RealProductRemoteDataSource implements IProductRemoteDataSource {
  final ApiClient _client;
  
  @override
  Future<List<ProductModel>> getProducts() async {
    final response = await _client.get('/api/v1/products');
    return (response as List).map((e) => ProductModel.fromJson(e)).toList();
  }
}
```
